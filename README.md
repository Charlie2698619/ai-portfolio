# Charlie AI 作品集

繁體中文個人作品集，預設採用「森林工作室」風格，包含六個專案主題、互動體驗，以及 PDF、Excel、PowerPoint 範例下載。

## 發布到 GitHub Pages

1. 建立儲存庫，例如 `ai-portfolio`。
2. 將本資料夾的所有檔案與子資料夾放在儲存庫根目錄，包含 `.nojekyll`；`index.html` 必須直接位於根目錄。
3. 開啟儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**，指定 `main` 分支與 `/(root)`，然後儲存。
5. 等待部署完成，使用 Pages 設定頁提供的網址開啟網站。

網站使用相對路徑，可放在 GitHub Pages 的專案子路徑。無須安裝套件或另外執行建置。

## 存取範圍

GitHub Pages 網站一般會對網路公開；即使原始碼儲存庫是私有，網站也不一定是私人。GitHub Free 的 Pages 功能需要公開儲存庫。若要讓面試官直接開啟，請先確認可公開網站及所附作品檔案。

## 內容與檔案

- `index.html`、CSS、JavaScript：網站與互動功能。
- `assets/`：作品圖片。
- `files/`：作品集 PDF，以及固定 2026 Q3 合成資料的可編輯 Excel、PowerPoint 範例。下載檔不隨網站篩選變動。

作品提及的 ChatGPT、Claude Code、Codex 等名稱屬於作品內容與技術工具介紹。此發布包不包含託管平台的頁尾標章、登入閘道或平台設定。
